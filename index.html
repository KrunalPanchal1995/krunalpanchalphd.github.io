Dr. Krunal R. Panchal

PhD, Mechanical Engineering, IIT Madras (2026) Process engineering for reacting systems: chemistry, uncertainty, CFD, and machine-learning surrogates

I try to understand the structure of a problem before optimizing it. A rate constant is a range, not a value — uncertainty is a first-class citizen in everything I build, not an afterthought bolted on at the end. I value methods that are accurate and interpretable, reproducible, and computationally honest about their own cost. When something doesn’t work, I’d rather document why than quietly move on — the clearest example is a 115-run statistical audit of my own scientific-ML results that found a supposed “10× improvement” was mostly seed noise. That finding is now part of the record, not something I buried.

One loop, from the chemistry to the process

Developing a reacting process, whether a flame or a plasma-etch recipe, is one loop: know the chemistry, simulate it, find out what controls the result and how sure you are, tune it against measurements, then build something faster and better from what you learned. MOSIAC is that loop for combustion chemistry. It builds the reaction mechanism, shows which reactions matter, calibrates against experiments, states the uncertainty, and reduces the model to what is essential. My current research takes the last step: running that reduced model inside a CFD solver, and letting a Neural-ODE surrogate stand in for the chemistry so the simulation is faster. A first demonstration works in a one-dimensional reacting-flow solver I wrote, and its accuracy is still being improved. It is not a validated model yet. Plasma chemistry is the same kind of problem with a different reactor, and I am studying it now through plasma-assisted pyrolysis.

How the work fits together

One loop, from building a model to using it

The same six steps run through everything here, in the order of Bloom's revised taxonomy: remember the chemistry, understand what controls it, apply it in simulation, analyse the uncertainty, evaluate it against experiments, and create something new from it. MOSIAC is that loop for combustion chemistry; the last step, running the calibrated model inside CFD and teaching a neural network to stand in for it, is current research.

  1. Construct build or import the reaction mechanism
  2. Explain which reactions control which measurements
  3. Simulate reactors, flames, cross-checked solvers
  4. Quantify and reduce how sure are we; keep only what matters
  5. Calibrate tune against experiments with honest error bars
  6. Use CFD and Neural-ODE surrogates (current research)
